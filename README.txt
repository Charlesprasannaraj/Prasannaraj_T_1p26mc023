OCEAN WORLD - CONTENT PAGE

Project files:
- index.html
- main.css

Built with:
- HTML5
- CSS3

Run:
1. Extract the ZIP file.
2. Open index.html in a browser.

Page features:
- Ocean-themed gradient header and footer
- Horizontal navigation menu
- Two-column article and sidebar layout
- New ocean image floated beside the article text
- Content about marine life and ocean conservation
- Sidebar links
- Fixed-width desktop layout; no mobile-responsive styling

Internet connection is required for Google Fonts and the remote sample image.
